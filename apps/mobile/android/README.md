# AIpinho Mobile Android

Native Kotlin Android client for the local AIpinho backend. The app is a backend client: it does not execute models, patches, shell commands, git commands, or arbitrary remote commands.

Connection profiles: ADB Reverse, Wi-Fi LAN, Tailscale, and Manual. Default service ports are 9088, 9089, 9098, and 9099. Token is paired at runtime and stored using Android Keystore.
