# Mobile User Guide

The mobile app exposes agent tabs for AIpinho, Lucio, Codex and Gemini.

Expected behavior:

- Sessions are separated by agent.
- Normal chat is human-readable.
- Timeline cards are sanitized.
- Raw remains hidden unless explicitly requested.
- Artifact downloads use authenticated backend calls.
- Approval and blocked states must be visible as actions or explanations.

Before a long run, confirm backend status and token configuration.
