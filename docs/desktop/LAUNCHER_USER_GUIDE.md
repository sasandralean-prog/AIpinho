# Launcher User Guide

The Launcher is the desktop cockpit for AIpinho multi-agent operation.

Expected surfaces:

- Dashboard.
- AIpinho, Lucio, Codex and Gemini tabs.
- Session controls.
- Timeline.
- Details inspector.
- Debugger.
- Artifacts.
- Safe actions and approvals.

Provider keys must never be shown in the Launcher. Status should show only configured/not configured and sanitized errors.
