# Launcher Project Selector

Launcher should use the Project Profiles API to let the user select a context for AIpinho, Lúcio, Codex or Gemini sessions.

Recommended controls:

- list profiles;
- detect profile from path;
- select profile;
- validate profile;
- show workspaces;
- show commands;
- show health.

Launcher must not store secrets inside profiles and must not expose raw file content in normal UI.
