# Desktop Agent Tab Contract

Every agent tab provides:

- independent persistent sessions;
- create, open, rename and delete actions;
- workspace input when supported;
- send and optional plan, preview or route-preview actions;
- active run cancellation;
- normal, details and raw display modes;
- provider and backend status;
- five-second polling only while the tab is selected.

Dialogs are native Tk windows styled with the AIpinho neon palette. Standard
Windows rename and delete dialogs are not used for chat session management.

The UI does not evaluate policy or grant capabilities.
