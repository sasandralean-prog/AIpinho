# Engineering Platform Matrix

These are engineering capabilities, not marketing promises and not AIpinho
runtime integration claims.

| Platform | Workspace | Git write | Local overlay access | repository_only | local_required | hybrid |
|---|---|---:|---:|---:|---:|---:|
| Codex PC | local checkout | yes | yes | yes | yes | yes |
| Devin Terminal | local checkout | yes | yes | yes | yes, when capability exists | yes |
| Devin Cloud | remote VM | yes | no direct factual access | yes | no | implementation portion |
| Replit Agent | Replit cloud | yes | no | yes | no | implementation portion |
| VS Code / Copilot local | local checkout | yes | yes | yes | yes, when capability exists | yes |

## Interpretation

- A cloud agent can edit code that affects local runtime, but cannot claim local
  GGUF, corpus, Pinhoabacaxi, Windows, hardware, or FireTest validation it did
  not observe.
- A local-capable agent can produce local proof only for resources actually
  available and exercised.
- Hybrid work should keep the same Git branch across cloud and local validation.
