# Skill Pack Manifest Schema

Campos principais:

- `skill_pack_id`
- `display_name`
- `slug`
- `version`
- `status`
- `category`
- `description`
- `included_skills`
- `required_capabilities`
- `optional_capabilities`
- `supported_agents`
- `supported_project_stacks`
- `supported_execution_modes`
- `risk_level`
- `policy_profile`
- `validation_profile`
- `artifact_policy`
- `memory_policy`
- `docs_ref`
- `tests_ref`
- `evidence_refs`

Manifests invalidos nao sao considerados saudaveis e nao devem executar.
