# Internal Skills Catalog

## Project Read-only Inventory

`internal.project_readonly_inventory`

Reads project structure through governed read tools and generates an inventory report artifact.

## Safe Markdown Report Generator

`internal.safe_markdown_report_generator`

Creates a sanitized markdown report artifact through Tool Gateway.

## Validation Runner

`internal.validation_runner`

Records governed validation evidence and generates a validation report.

## Mobile UX Static Audit

`internal.mobile_ux_static_audit`

Experimental read-only UX audit for mobile project files.

## Artifact Bundle Exporter

`internal.artifact_bundle_exporter`

Creates a governed artifact bundle manifest without exposing tokens in URLs.
