# Project Charter — AIpinho

## Mission

AIpinho is a governed cognitive/runtime system that transforms language into bounded action while preserving authority, evidence, semantic truth, and honest completion.

## Refusal

It must not pretend to know, authorize, execute, validate, or complete more than current evidence and authority prove.

## Project-specific invariants

- Model output is never execution, policy, approval, or truth authority by itself.
- Mission/resource/human authority must remain explicit and bounded.
- RuntimeTruth/SpeakerTruth constrain final claims; local phase completion cannot fabricate mission completion.
- Context and semantic cache transport or accelerate evidence; they do not create authority.
- Compatibility, diagnostic, role, dispatcher, broker, and fallback surfaces must not become parallel semantic runtimes.
- FireTest behavior is evidence/regression input, never production hardcode.
- Generated `genome/` is an implementation snapshot/inventory; `Engineering_Genome/` is governance and continuity. Do not conflate them.

## Engineering posture

Prefer explicit identity, provenance, capability discovery, typed policy, bounded fallbacks, observable decisions, and semantic tests. Generalization follows demonstrated variation or a clear contract boundary; the Genome is not a demand for maximal abstraction.
