# AIpinho H1 → H4 Roadmap

These horizons describe cognitive maturity, not software modules.

## H1 — Operational reliability / consciousness
Goal: make AIpinho a reliable governed agent.

Themes:
- truth;
- terminality;
- evidence;
- explicit contracts;
- bounded runtime behavior;
- trustworthy completion semantics.

The system should not invent, hide, silently bypass, execute what it does not understand, or claim success without evidence.

H1C0.R2 concentrated heavily on this foundation.

## H2 — Collaborative cognition
Directional goal: think *with* the user rather than merely execute well-formed operations.

Possible themes:
- shared cognitive state;
- iterative hypothesis refinement;
- richer internal representations;
- collaborative planning;
- ambiguity management;
- memory that assists reasoning without accidentally becoming authority.

The Rafa↔Lúcio ping-pong dynamic is an informal inspiration, not yet a runtime contract.

## H3 — Supervised evolution
Directional goal: allow AIpinho to improve representations, strategies, and capabilities under explicit supervision and governance.

Possible themes:
- self-diagnosis;
- proposal generation;
- governed architecture evolution;
- before/after evidence;
- human approval for meaningful structural change.

H3 must not mean uncontrolled self-modification.

## H4 — Long-term companionship
Directional goal: sustained, context-rich collaboration over long time horizons.

Possible themes:
- durable relationship context;
- continuity;
- personal cognitive partnership;
- provenance-aware and consent-aware memory;
- stable interaction dynamics;
- understanding why old decisions exist.

## Principle
Do not skip maturity layers because a speculative feature sounds exciting.

A capability belongs in a horizon when its prerequisites are actually reliable.

## Current state
At the end of H1C0.R2:
- R2 reliability/governance scope is consolidated;
- FireTest 5 remains NOT_READY;
- next frontier is capability-based semantic media observation.

`R3.01` is a wave/frontier sequence label. It does not by itself mean Horizon 3 as a whole has been achieved.
